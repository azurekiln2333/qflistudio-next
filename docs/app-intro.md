# QFLIStudio+ 应用介绍（8000 字）

## 一、先认识这个应用

QFLIStudio+ 是一个代码编辑器。它装在手机上，也装在电脑上。它用 Flutter 编写，界面遵循 Material 3 设计规范。

它把几件事放进同一个应用。第一件是写代码。第二件是管项目文件。第三件是读教程。第四件是和人讨论。第五件是把代码送到云端终端里跑。

它不是远程桌面。代码文件保存在你的设备上。打开应用就能新建项目。写完就能保存。

它的名字里有两个部分。QFLI 是产品标识。Studio 是工作室的意思。加号表示全能版。主应用同时提供编辑、教程、讨论和云端能力。

它还有一个特点。同一个编辑器内核被拆成十一个单语言版本。每个版本只服务一门语言。想专注写 Python 就装 PyFlow。想专注写 C 就装 C Forge。

下文按功能逐个说明。你先看界面，再看编辑器，然后看运行、终端、云端、社区和账户。

## 二、界面与导航

应用的底部有四栏。第一栏是主页。第二栏是教程。第三栏是讨论。第四栏是我的。

主页打开就是项目列表。教程页展示分门别类的学习内容。讨论页是社区。我的页面放账户、积分和个人数据。

单语言版本只有三栏。第一栏是本地项目。第二栏是本地 JSON 教程。第三栏是示例代码。它不连接社区，也不上传任何内容。

主页顶部有搜索框。输入名称会立刻过滤列表。输入路径也能过滤。过滤在你打字的过程中生效。

主页右上角有更多菜单。菜单里可以添加现有项目。也可以移除失效项目。

主页的下拉可以刷新。列表短的时候也支持下拉。空列表同样支持下拉。

从主页可以进入编辑器。编辑器里再进入终端、预览和设置。

编辑器上方是文件标签栏。下方是可展开的终端面板。右侧是代码鸟瞰条。

外观有浅色和深色两套。颜色跟随系统设置。切换外观会立即生效。

启动过程做了专门处理。原生窗口和 Flutter 画面的底色保持一致。所以看不到白屏闪一下。

数据加载发生在首帧之后。项目列表和编辑器不会和首帧争抢主线程。社区页面按需初始化。你没有进入讨论页，它就不会提前工作。

## 三、项目管理

新建项目时先选语言。选定位到对应的语言文件目录。C 项目进入 cProjects。Java 项目进入 javaProjects。Python 项目进入 pythonProjects。

项目建好后会自动生成模板代码。模板代码会立刻在编辑器里打开。

项目允许重名。目录发生冲突时，应用会给目录名加时间戳后缀。显示名称不会被时间戳污染。显示名称保存在项目内的配置文件里。

项目卡片会显示两样东西。第一样是显示名称。第二样是文件路径。路径方便你确认文件落在哪里。

每张卡片提供三个动作。第一是打开。第二是在资源管理器中显示。第三是从列表移除。

项目列表会持久保存。下次打开应用还在原来的位置。

用固定模板的项目可以导出为压缩包。压缩包带着项目配置一起走。导入时会重新选择语言目录。导入时允许显示名称重复。配置里的名称会被恢复。

项目回收站放在我的页面。它是本地功能。不登录也能使用。

回收时会先解压到临时目录。绝对路径会被拒绝。越出目录的路径会被拒绝。符号链接会被拒绝。目标位置已有文件时不覆盖。

恢复项目后会把它重新登记到项目列表。

创建目录时会先同步占位。占位成功后才写文件。这样并发新建不会撞到同一个目录。

外部添加的只读目录仍会尝试写配置。写失败不会改变项目在列表里的显示。

导出压缩包时会读取当前配置。所以改名后的项目会带着新名字走。

导入时先选语言目录。语言目录决定文件落在哪里。配置里的语言只用于校验。

## 四、编辑器的主体能力

编辑器基于 re_editor 改造。文件以标签页形式打开。每页对应一个文件。

文件有未保存修改时，标签上出现圆点。关闭标签前会询问。确认后才丢弃修改。

左侧有行号。代码可以折叠。折叠状态在切换标签后保留。

语法高亮由 re_highlight 提供。HTML 文件里的 CSS 和 JavaScript 也会着色。

查找和替换用 Ctrl 加 F 唤出。可以区分大小写。可以按正则匹配。

跳转到行用 Ctrl 加 G。输入行号就跳过去。

格式化用 Ctrl 加 I。格式化结果直接写回编辑器。

保存用 Ctrl 加 S。在 macOS 上用 Cmd 加 S。

右侧有一条代码缩略图。点击缩略图会跳到对应位置。拖动缩略图会连续滚动。缩略图只采样部分行。它不会为整份文件逐个绘制。

左侧文件树做成圆角卡片。它没有阴影，只有细描边。宽屏时可以收起。窄屏时以抽屉形式出现。

编辑器的字体可以调整。内置 Roboto Mono。包含常规、粗体、斜体和粗斜体四种字形。

字体大小可以改。行高可以改。也可以打开粗体和斜体开关。双指缩放可以改字号。松手后字号会被保存。

中文和特殊字符走系统字体回退。所以中文注释不会变成方框。

代码、终端和预览共用同一个等宽字体。界面文字仍然使用应用主题字体。

常用快捷键如下。

| 动作 | Windows 与 Linux | macOS |
| --- | --- | --- |
| 保存 | Ctrl 加 S | Cmd 加 S |
| 查找替换 | Ctrl 加 F | Cmd 加 F |
| 跳转到行 | Ctrl 加 G | Cmd 加 G |
| 格式化 | Ctrl 加 I | Cmd 加 I |

编辑器视图按文件身份缓存。同一文件再次打开会复用视图。主题或字体变化会让缓存失效。

不活跃的标签会暂停动画计时。切回来时恢复。

文件修改时间在读写时更新。光标移动不查文件系统。

## 五、代码高亮与主题定制

入口在我的页面。路径是设置、代码高亮。编辑器内的设置入口也能进同一页。

语法高亮可以整体关闭。关闭后编辑器仍能正常读写文件。

主题有几种现成选择。可以跟随应用外观。可以用 Visual Studio 浅色。可以用 GitHub 深色。

每个颜色都能单独改。关键字一种颜色。字符串一种颜色。注释一种颜色。数字一种颜色。

HTML 的标签和属性可以分别设色。CSS 的属性和选择器可以分别设色。

改乱之后可以一键恢复主题默认值。

应用支持导入外部配色。可以导入 TextMate 的 tmTheme 文件。也可以导入 VS Code 的 tokenColors 配置。JSON 和 JSONC 都能读。

配色支持前景和背景。支持光标和选区。支持当前行高亮。支持加粗、斜体和下划线样式。

应用也支持导入基础语法定义。格式是 tmLanguage 的 JSON 版本。导入时指定它对应的文件后缀。

同一个语法标识再次导入会替换旧配置。多个语法争同一后缀时，最近导入的优先。

兼容范围写得很清楚。捕获组 0 的整体配色可以使用。捕获组 1 及以上会被拒绝。

contentName 会被拒绝。while 条件会被拒绝。injections 会被拒绝。递归 include 会被拒绝。外部语法引用会被拒绝。

被拒绝时导入会说明原因。不会留下半成品配置。

Oniguruma 专用正则不支持。内联修饰符不支持。begin 与 end 之间的反向引用不支持。

所以不能宣称任意 VS Code 语法都能直接导入。这一点在文档里明确写出。

作用域匹配按具体优先。普通作用域能用。作用域前缀能用。逗号分隔的多个作用域能用。数组形式也能用。

父作用域组合选择器不完整。语义令牌颜色不应用。主题里的 include 需要先手动合并。

这些限制写在文档里。用户能预期导入后的效果。

导入过程不联网。导入过程不读取配置外部的文件。导入过程不执行配色里的脚本。

配置保存在应用的设置文件里。重启后自动恢复。删除配置不会动原始主题文件。

## 六、运行代码

编辑器有运行按钮。运行方式按语言分流。顺序决定优先级。

第一优先级是语言应用注入的运行时。例如 C 版自带的应用内解释器。它直接接管运行。

第二优先级是 HTML。应用在本机起一个 HTTP 服务。地址是 127.0.0.1。然后用浏览器打开预览。

第三优先级是 Python 和 Dart。桌面端直接调用本机解释器。输出进入终端面板。

第四优先级是 Java、C 和 C++。桌面端先编译再运行。输出同样进入终端面板。

移动端情况不同。手机上没有可用的编译工具链。应用会引导你使用在线终端。

如果本地命令不存在，或者本地返回 127，应用可以回退到在线执行。只有支持的语言可以回退。

运行前会保存当前打开的文件的快照。快照用于还原运行环境。也用于送给云端执行。

预览页面会注入一小段脚本。它的作用是把页面日志送回编辑器。编辑器把日志显示在终端面板。

浏览器里发生的错误也会被收集。你在系统浏览器里打开预览也能看到日志。

运行会先展开终端面板。等第一帧画完再保存快照。这样输出区域已经准备好。

重复点击运行会被忽略。正在准备的任务不会被第二个请求打断。

## 七、终端

终端面板在编辑器内部。它不是一个单独的页面。这样切换时不会丢掉输出。

终端有两种模式。第一种是本地终端。第二种是在线终端。

本地终端是一个响应式 shell。它在应用沙箱内执行命令。单条命令有 30 秒超时。

在线终端需要先登录。业务接口把你的请求转给独立的执行服务。执行服务在隔离的沙箱里跑命令。

登录状态不清楚时，终端会先提示登录。它不会提前占用任何资源。

沙箱只在首次运行时创建。打开应用不会创建沙箱。打开项目也不会创建沙箱。

面板隐藏时执行继续。输出继续累积。你切回来还能看到历史。

显式关闭终端会取消请求。应用还会尝试释放沙箱。

终端会显示真实的排队位置。也会显示真实的初始化阶段。它不会编造一个百分比进度。

一次提交的项目快照有上限。最多 64 个文件。解码后总量最多 256 KiB。

超出上限的项目会被直接拒绝。应用会先给出诊断，再把请求发出去。

在线终端支持这些语言。Python、JavaScript、TypeScript、Lua、Java、C、C++。也支持 Shell、Go、Rust、Dart、PHP 和 Ruby。

Kotlin 和 C# 没有云端运行时。应用会把它们标为不支持。应用不会把不支持的工程提交上去。

云端构建在离线模式下跑。Go 使用 GOTOOLCHAIN 本地模式。Go 代理被关闭。Rust 使用 cargo 的离线模式。

沙箱里的依赖不能在会话中下载。所以需要远程依赖的工程要先准备好本地副本。

单条命令的执行期限是 60 秒。客户端请求超时是 110 秒。业务转发超时是 85 秒。反向代理建议至少 120 秒。

会话内的文件只活在这一段时间里。重置会清除。超时会清除。断开连接会清除。到期和服务重启也会清除。

云端项目不挂载进沙箱。所以终端读写不到你的云盘文件。

事件流用 NDJSON 传输。客户端限制总线上限为 2 MiB。单行上限为 700 KiB。

事件类型和阶段名都做白名单校验。只允许一个最终结果。错误帧会转成异常。

输出块只渲染一次。最终结果里的输出不会重复打印。

跨事件的部分行会被保留。终端历史有长度上限。

终端支持粘贴和换行输入。长输出会自动滚到底部。向上滚动时不强制跳回。

未登录时终端只显示登录提示。它不会预先分配沙箱。它也不会占队列位置。

排队满时服务端返回明确错误。应用显示服务端消息。应用不做无限自动重试。

请求被取消时会关闭本次连接。隐藏面板不会取消。关闭编辑器才会取消。

## 八、云端项目与 Git

云端项目是私有云盘。它需要登录后创建。

新建时选好语言。模板文件会自动上传。你不需要手动传。

编辑云端项目时会有自动同步。停止输入 2.5 秒后写盘并推送。

点了保存会立刻推送。不等 2.5 秒。

状态栏会显示当前同步状态。同步中一种显示。已同步一种显示。离线一种显示。

在文件树里删除文件，会同步删除云端副本。

也可以手动从云端拉取。拉取会用服务器版本覆盖本地版本。

本地项目可以用 Git。这部分在桌面端可用。它调用本机的 git 命令。

支持的操作包括初始化仓库。包括查看状态。包括提交。包括看历史。包括配置远程仓库。包括推送。包括拉取。

云端项目原本的宿主机 Git 接口已经关闭。云端文件同步仍然可用。

移动端没有 git 二进制。所以本地项目在手机上不能直接提交。

在线终端是无外网的临时沙箱。它不能直接连接 GitHub 或 Gitee。

这些边界都在应用里如实提示。应用不会假装完成一次失败的推送。

## 九、社区与教程

社区有两种内容类型。第一类是教程。第二类是讨论。

内容按专区组织。现有专区覆盖 Java、Python、C 与 C++、前端、Flutter 和鸿蒙。

发布时可以加标签。一条内容最多带五个标签。

搜索会匹配标题和正文。结果分页加载。列表可以下拉刷新。

详情页可以点赞。可以分享，方式是复制内容。可以发表评论。评论按树形展示，支持回复。

自己发布的内容可以删除。删除动作只对自己可见。

发布页先选类型。再选专区。再加标签。最后提交。

教程页不依赖网络。它读取随应用打包的本地内容。所以断网也能学习。

每条教程按语言归类。教程里给出可运行的示例。示例代码可以一键复制。

示例页展示可复制的代码片段。它和教程来自同一份数据。所以版本始终一致。

讨论入口放在合适的位置。工作室首页不显示讨论入口。这样首页只专注项目列表。

社区页面是懒加载的。讨论列表记住滚动位置。切回列表不会跳回顶部。

详情页的评论按层级缩进。回复挂到对应评论下面。

点赞状态按登录账号区分。切换账号后重新拉取。

单语言版本的主页只列本地项目。它的教程页读本地教程文件。它的示例页读同一份数据。

全能版多出讨论和云端入口。这些入口需要登录后才可用。

关于页记录版本号。也记录开源许可和协议入口。许可清单包含内置字体的授权文本。

## 十、账户与登录

登录支持账号密码。用户名和密码都是原生输入框。

提交前会先做一次验证询问。接口是登录需求探测。它验证账号密码，然后返回需要哪些验证因子。

第二因子对话框先出现。验证码对话框随后出现。两者都收齐才提交最终登录。

修改用户名会重置验证状态。修改密码也会重置验证状态。

因子码填错会重新收集因子。验证码填错时保留因子码。原因是服务端先校验验证码，再消费因子。

登录接入 AZK 的 OAuth2 网关。授权页会换回一个登录码。

鸿蒙版本支持华为账号。登录前只显示脱敏设备手机号。

授权后拿到已核验手机号。手机号匹配已有账号时直接登录。

需要绑定时会返回绑定标识。应用打开已有账号表单。你可以用原密码、多因子和验证码完成绑定。

也可以选择跳过。跳过会创建新账号。绑定标识不会被持久保存。

服务地址固定为官方服务。地址写在共享内核的配置里。客户端没有更换服务器的入口。

切换部署域名需要重新构建应用。应用设置里不提供自定义服务地址。

登录态只接受同一来源。跨站的令牌不会被接收。

服务端错误会带请求标识。请求标识会显示在错误提示里。凭据和令牌不会出现在诊断信息中。

登录失败会保留已填内容。修改账号字段会清空验证状态。旧因子不会被复用。

绑定流程有两个出口。一个出口是验证已有账号。另一个出口是创建新账号。

过期的绑定请求需要重新授权。应用不会保存过期标识。

协议地址只接受 HTTPS。空地址会显示未发布状态。应用不打开外部浏览器。

应用内可以打开用户协议和隐私政策。鸿蒙版本用原生网页页打开。该页面支持返回、刷新、加载中和错误提示。

## 十一、我的页面

我的页面顶部是资料卡。它按 Material 3 的样式绘制。

资料卡下面是积分和签到。签到后会显示连续天数。

每日任务页展示可完成的任务。完成任务会记录积分明细。

数据管理区集中放本地工具。这里还有项目回收站。

文件回收站处理被删除的文件。文件备份按开关自动保存副本。版本历史按原路径分组。

备份开关的状态会被记住。下次启动沿用上次的选择。

恢复文件会先检查来源。绝对路径被拒绝。越界路径被拒绝。符号链接被拒绝。目标已存在时不覆盖。

恢复版本前会先备份当前文件。备份成功后才允许覆盖。备份失败就不覆盖。

恢复后记录仍然保留。彻底删除需要单独确认一次。

回收记录带一份元数据文件。元数据记录原路径、项目名、显示名和时间。

旧记录没有元数据时仍然可见。恢复时由你选择目标位置。

版本历史按原路径分组。旧记录退回按项目名加文件名分组。

编辑器的版本列表会过滤元数据。不同目录的同名文件不会混在一起。

外观设置在同页。可以选择浅色、深色或者跟随系统。

编辑器字体设置也在同页。字号、行高、粗体、斜体都能改。

底部显示备案号和查询入口。登出状态下仍然显示。点击会用应用内网页打开查询页。

## 十二、教程、示例与语言专属版本

共享内核里保存着教程数据。每个语言一个文件。路径按语言命名。

语言专属版本只改三个文件。第一个是主入口的档位。第二个是运行后端。第三个是接线测试。

平台工程是复制来的公共部分。所以十一个版本的行为高度一致。

现有版本清单如下。C 与 C++ 版本提供 Forge。Web 版本提供 WebForge。Python 版本叫 PyFlow。

Java 版本叫 JVMX。Lua 版本叫 Script。Dart 版本叫 DartWing。Rust 版本叫 RustCore。

Go 版本叫 GoShift。SQL 版本叫 SQLab。JSON 版本叫 QFLIJson。笔记版本叫 QFLINote。

单语言版本是本地版。它有本地项目、本地教程和示例代码。它不上传内容，也不用登录。

主应用是全能版。它保留社区、云端项目和在线终端。

如果某一门语言还没有版本，可以用生成器创建。生成器会搭好平台工程。它还会安装鸿蒙侧的依赖。

运行时是否可用会如实展示。没有解释器的语言不会伪造运行结果。

## 十三、十一个语言版本逐个看

C 与 C++ Forge 面向系统编程。它带应用内解释器。示例覆盖指针、结构体和文件读写。

WebForge 面向网页开发。它内置 HTML 预览。CSS 和 JavaScript 都在同一个编辑器里高亮。

PyFlow 面向 Python。桌面端直接调用解释器。手机上可以把代码送到云端终端。

JVMX 面向 Java。桌面端编译后运行。移动端提示使用在线终端。

Script 面向 Lua。它适合写小脚本。示例覆盖表、函数和字符串处理。

DartWing 面向 Dart。桌面端直接运行。它的语法高亮与主应用一致。

RustCore 面向 Rust。桌面端离线构建。云端构建关闭了网络拉取。

GoShift 面向 Go。桌面端离线构建。云端构建固定使用本地工具链。

SQLab 面向 SQL。它展示查询语句和结果格式。执行依赖可用的数据库环境。

QFLIJson 面向 JSON。它提供格式化和校验的练习。

QFLINote 面向笔记。它用纯文本记录内容。

每个版本的教程独立成文件。你可以只读自己关心的语言。

每个版本的界面一致。学会一个就能用另一个。

## 十四、平台覆盖

工程目录覆盖多个平台。安卓、iOS 和鸿蒙都有。Windows、macOS 和 Linux 也有。浏览器端同样保留。

同一套编辑器内核在各平台共享。界面和快捷键保持一致。

桌面端的能力最完整。本地终端、编译运行和 Git 都能用。

移动端的能力受限。安卓和 iOS 上可以编辑、保存和预览网页。需要编译的语言走云端终端。

鸿蒙版本有原生启动页。启动页显示真实进度。进度由 Dart 侧上报。原生侧渲染进度条。

鸿蒙的 release 包会把 Dart 代码编译成机器码。debug 包走即时编译。两者体积差别明显。

鸿蒙的协议阅读器是原生页面。它不在 Flutter 里叠一层纹理。这样长文滚动更稳。

安装包按平台分别构建。安卓包提供单一架构版本，体积更小。

鸿蒙包分 debug 与 release 两种。release 包体积约为 debug 的一半。

桌面端用各自平台的构建产物。界面与快捷键随平台微调。

浏览器端保留完整编辑器。本地文件读写受浏览器限制。

各平台的字体渲染略有差异。等宽字体在桌面端更整齐。

鸿蒙版本申请了联网权限。也申请了网络状态权限。还申请了剪贴板权限，用于粘贴代码。

安卓版本只申请联网权限。两个版本都不申请通讯录与相册权限。

桌面端不需要额外权限。文件访问由系统对话框授权。

真机表现比模拟器更可信。发布前建议在真机验收一次。

## 十五、数据存放与隐私边界

本地项目保存在应用的数据目录。按语言分子目录。

项目配置写在项目内部的隐藏目录里。显示名称、语言和类型都在其中。

应用设置写在单独的设置文件里。字体、外观、备份开关都在这里。

云端同步只作用于云端项目。本地项目不会自动上传。

在线终端的代码会进入隔离沙箱。沙箱没有外网。沙箱按会话回收。

执行服务只监听本机端口。对外通过受来源限制的内部连接接入。

客户端不持有内部密钥。客户端只转发已认证的用户请求。

诊断信息只记录阶段与标识。不记录密码。不记录令牌。

协议和隐私政策在应用内可查。备案信息在个人页常驻显示。

## 十六、性能上的取舍

启动分两步。先画出第一帧。再加载本地数据。

主页的页面会被缓存。来回切换不重建整棵树。

编辑器视图按文件缓存。关闭文件时会从缓存移除。

不活跃的页面会暂停计时器。这样动画不会在后台空跑。

高亮输入会合并处理。规则解析结果会缓存。

长行会走快速路径。超大文件会退回纯文本。超时也会回退。

自动保存按文件串行。旧保存不会清掉新修改的脏标记。

缩略图有采样上限。它不会为整份文件逐行计算。

光标移动不会触发文件系统查询。修改时间在读写时更新。

这些处理的目标很清楚。让滚动和输入在手机上保持顺滑。

应用根节点只关心主题与启动状态。改编辑器设置不会重建整个应用。

页面只监听自己用到的状态。资料变化不会触发项目列表重绘。

相邻切换有短促滑动。跨页切换直接跳到目标。中间页面不会被构造。

## 十七、适合谁使用

第一类是在校学生。他们要在手机上练习语法和算法。教程和示例就在同一页。

第二类是通勤路上写代码的人。地铁上没法打开笔记本。手机可以继续改昨天的文件。

第三类是准备面试的人。他们需要反复改同一道题。项目列表能保留这些文件。

第四类是讲课的老师。他们可以在课堂上打开示例。修改后立即预览结果。

第五类是快速验证片段的人。写几行 HTML 就能看到效果。写几行 Python 就能看到输出。

第六类是需要云端算力的人。手机跑不动的语言交给在线终端。

这个应用不适合所有人。大型工程构建不适合它。需要完整原生工具链的项目不适合它。

需要图形化调试器的项目也暂不适合。断点调试属于编辑器里的离线调试能力，按产品提供情况展示。

需要多仓库协作的大团队，用桌面 IDE 更合适。这个应用的目标是轻量和随身。

举几个具体场景。

场景一。你在公交上想起一个正则写法。打开应用，新建一个空项目，写完保存。到公司再复制进工程。

场景二。你在准备比赛。教程里有示例，示例可以复制，改完直接看输出。

场景三。你要给同事演示一段 HTML。手机起本地服务，浏览器打开就能看。

场景四。你在外地，只带了手机。需要跑一段 Python。连上在线终端，等几秒看到结果。

## 十八、常见问题

问：为什么手机上跑不了 Java 和 C。答：手机没有可用的编译器。应用会引导你用在线终端。

问：为什么在线终端要先登录。答：沙箱要按账号计量。未登录不能分配资源。

问：为什么手机不能直接连 GitHub。答：临时沙箱没有外网。拉取请用桌面端。

问：换手机怎么带走项目。答：把项目导出成压缩包。也可以把项目放进云端项目。

问：我的代码会被上传吗。答：本地项目不会。只有云端项目和在线终端会传输。

问：教程要联网吗。答：教程随应用打包。断网也能看。

问：字体能用自己装的吗。答：可以选系统等宽字体。内置字体是 Roboto Mono。

问：高亮主题能用自己的吗。答：可以导入 tmTheme 或 VS Code 配色。导入范围有明确说明。

问：误删的文件能找回吗。答：去我的页面找文件回收站。版本历史也能恢复旧版本。

问：标签太多会乱吗。答：可以随时关闭标签。未保存的文件会先确认。

问：应用有多大。答：安卓 release 包约 27 MB。鸿蒙 release 包约 80 MB。

问：支持几门语言。答：主应用覆盖十余门语言。单语言版本有十一个。

问：能离线编辑吗。答：能。编辑、保存、本地预览都不需要网络。

问：教程内容会更新吗。答：教程随应用版本更新。断网时仍读本地内容。

## 十九、写在最后

QFLIStudio+ 的出发点很简单。让写代码这件事不再被设备限制。

它不追求把所有桌面能力搬进手机。它把最常用的动作做顺。新建、编辑、查找、预览、运行、保存、同步。

界面用 Material 3 的语言。深色和浅色都能用。字体、配色和字号都可以调。

十一个单语言版本让学习更聚焦。全能版让工作更连贯。

如果你只想要一个顺手的编辑器，直接新建项目开始写。

如果你还想学点东西，教程页有分类内容。

如果你想和人交流，讨论区可以发帖和回复。

如果你手上只有手机，在线终端可以帮你跑一次结果。

这就是这个应用的全部主张。在一个应用里写完、跑完、学完。

版本号写在关于页。升级不会删除本地项目。

设置与项目分开保存。卸载应用会清掉本地数据。重要项目请先导出。
