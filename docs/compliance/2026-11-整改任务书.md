## 2. 架构要求：公共内容审核服务（用户明确要求解耦、可复用）

内容审核做成**独立仓库、独立部署的服务**，建议放在 `D:\MyNewProjects\azurekiln-moderation`。QFLI 和网关都只是接入方，以后其他项目也直接接入。不得把审核逻辑写死在 QFLI 业务代码里。

- 多应用接入：每个接入方有 `appId` 和密钥，接口鉴权；配置和数据按 app 隔离。
- 文本审核 `POST /v1/text/check {scene, text, userId?, ip?}`，返回 `{decision: pass|block|review, categories, hits}`。
  - 先做规范化再匹配：全半角、大小写、繁简、去掉插入的空格、符号和零宽字符。这对应"违禁品样本变异审核"。
- 词库：
  - 分类包括涉政、色情、赌博、毒品、枪支弹药、管制器具、诈骗、暴恐、违禁品、广告引流、自定义。
  - 提供管理接口增删改。改动 **10 分钟内生效**（承诺书要求），用热加载，不要求重启。
  - 初始词库可导入开源中文敏感词库。
- 图片审核 `POST /v1/image/check`：provider 可插拔；没有配置 provider 时进入人工审核队列。用于头像等图片。
- IP 规则 `POST /v1/ip/check`：IP 和 CIDR 黑名单，可选地区限制。
- 人工审核队列：用于"先审后发"。按 app/scene 设置开关，提供待审列表和审核结果查询或回调。
- 举报中心：
  - 提交接口：`targetType`、`targetId`、`reporterId`、`reason`。
  - 管理员受理和处理，记录处理结果。
  - 记录留存 365 天。
- 审计：所有判定、审核、举报处理都落库，留存 365 天。
- 提供 Node SDK，例如仓库内的 `packages/client`：
  - 带超时设置。
  - 支持 failClosed：发布类场景在审核服务不可用时拒绝发布，并提示"审核服务暂不可用"。

### W2 QFLI 服务端（`qflistudio/azurekiln-qfli-server`）及部署
- **日志**
  - `src/audit.js` 中 `RETENTION_DAYS` 改为 365，`src/db.js` 中 SQLite 和 MySQL 两处清理语句一起改。
  - 审计表增加 `port`、`platform`、`login_type` 字段。
  - 登录、注册、登出都要记录。平台取自客户端请求头 `X-Client-Platform`。
- **可信代理**
  - 不再直接信任客户端传来的 `X-Forwarded-For`。只信任反向代理设置的 `X-Real-IP` 和 `X-Real-Port`，或正确配置 Express `trust proxy`。
  - nginx 增加 `proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Real-Port $remote_port;`。
- **实名门槛**
  - 新增中间件：没有已验证手机号的账号，以下服务一律返回 403，`errorKey: realname.required`：社区浏览、发帖、评论、点赞、举报，云项目，在线终端，AI，SQL 沙箱。
  - 本地内置教程不受影响。
- **华为登录**：`src/routes/auth.js` 的 `/huawei/skip` 和 `/huawei/bind`，在 `phoneAvailable === false` 时直接拒绝，提示"请使用已绑定手机号的华为账号"。
- **接入审核服务（W1 SDK）**
  - 发帖的标题、正文、标签，以及评论、昵称、简介，都要走文本审核。
  - 发布前先查 IP 规则。
  - 先审后发开启时，新内容状态为 `pending`，只有作者和管理员可见。
- **发布限流**：发帖、评论按用户分别限制每分钟和每天的上限，可以复用 `terminalRateLimited` 的思路，超限返回 429。
- **封停**：管理员可禁言或封停账号，被封停账号禁止发布。操作写入审计。
- **管理员处置**
  - 新增 `DELETE /api/admin/posts/:id` 和 `/api/admin/comments/:id`，必须填写原因，写入审计 `admin.*`。
  - 管理员可查看举报并处理，可开关先审后发，词库和 IP 规则可代理或跳转到审核服务的管理接口。
- **举报**：`POST /api/reports`，转发到审核服务的举报中心，同时写本地审计。
- **永久注销**：`POST /api/users/me/deactivate`
  - 需要二次确认。
  - 删除本站数据：业务表通过级联删除，另外删除 `data/cloud/u<id>` 和 `data/terminals/u<id>` 目录。
  - 调用网关注销统一账号（W4 提供接口），吊销所有会话。
  - 审计日志保留 365 天，但其中的个人标识去标识化。
  - 即时完成，最长不超过 15 个工作日。
- **联网搜索下线**：服务端 `web_search` 不再调用 `www.bing.com`（`src/web-search.js`），工具也不再对外暴露。`web_fetch` 保留。

  - 响应里加 `aiGenerated: true`，供客户端做标识。
- **部署**：上线到 `qfli.suanxiwanjie.cn`（8.138.227.60），执行数据库迁移、更新 nginx 配置、做冒烟测试。

## 4. 验收标准（claude-df 会逐条复测）

1. 登录、注册日志包含用户ID、平台、登录类型、IP、端口、时间；代码和线上配置中的保留期都是 365 天。
2. 没有手机号的账号，使用社区、云项目、终端、AI、SQL 都被拒绝，并有绑定引导。
3. 没有手机号的华为账号无法跳过绑定直接建号；鸿蒙端看不到"其他方式登录"和注册入口。
4. 敏感词会被拦截，包括插入空格、全角、繁体等变体；词库新增后 10 分钟内生效；昵称、简介也会被拦截。
5. 管理员能删除他人的帖子和评论，并有处置记录；举报可以提交、处理和查询。
6. 连续快速发帖会被限流；IP 黑名单命中后禁止发布；先审后发打开后，新内容不公开。
7. App 内可以永久注销账号；注销后无法再登录，个人数据被删除，日志已去标识化。
8. 设置里能找到用户协议、隐私政策（不超过 4 次点击）和撤回同意入口。
9. 客户端和服务端都没有 bing.com 的调用；AI 回复和 AI 生成的文件都有标识；鸿蒙版不能自定义 AI 接口。
10. Mate 60 和 Mate X5 上顶部不再与挖孔区、状态栏重叠。
11. 公共审核服务独立部署；QFLI 和网关都通过 SDK 接入，审核逻辑没有写在业务代码里。
12. 所有仓库测试通过；提交信息符合规范且没有署名；服务已部署到线上。
