# 大陆企业 / 个体工商户讨论区上线清单

适用前提：用户已确认使用中国大陆服务器，由企业或个体工商户运营；服务地址为 `https://qfli.lqsxm666.top`。整理日期：2026-09-15。

## 先确认哪些手续适用

**有讨论功能并不是网站备案的唯一触发条件。** 大陆互联网信息服务本身就需要核对备案/许可；论坛和评论在此之外还有实名、内容管理和安全评估责任。

| 事项 | 你需要做的工作 | 向谁办理 / 核实 |
| --- | --- | --- |
| 网站 ICP 备案 / 经营许可分类 | 核对 `lqsxm666.top` 的域名实名、现有备案主体、服务器接入信息；如已有个人备案，需要按实际运营主体办理变更或新增事项 | 云服务器接入商、主体住所地省通信管理局 |
| APP 备案 | QFLIStudio+ 的联网功能需要 APP 备案，网站备案不能替代；准备包名/Bundle ID、签名证书信息、公钥/指纹等平台要求的资料 | 接入商或分发平台提交，省通信管理局审核 |
| 公安联网备案 | 按全国互联网安全管理服务平台及属地公安要求办理；通常在网站开通后 30 日内完成相应联网备案 | [公安备案平台](https://beian.mps.gov.cn/) / 属地网安 |
| 论坛/评论安全评估 | 论坛属于《具有舆论属性或社会动员能力的互联网信息服务安全评估规定》列明的形态。上线或增设相应功能前完成自评及适用的报告提交 | 所在地地市级以上网信部门、公安机关及其指定平台 |
| 增值电信业务经营许可是否需要 | 提交具体业务说明：软件授权、云同步、收费信息服务、付费内容、在线算力等；不能简单把“卖会员”直接等同于或排除 ICP 经营许可 | 省通信管理局 |

子域名不意味着可以借用其他主体的备案。实际填报根域名、接入与 APP 使用域名的方式，以接入商核验要求为准。

**主体建议：** 如果计划长期运营收费社区和云服务，优先评估公司主体。个体工商户是否能承载具体备案业务、是否满足可能涉及的经营许可条件，需要事先确认；涉及增值电信经营许可时通常有公司主体等准入要求。不要先收款，再发现主体不适合。

不要照搬多年前的“BBS 专项审批”教程。按现行备案、经营许可分类、论坛/评论管理及安全评估要求办理。普通编程教程也不应直接被等同于新闻采编或办学培训；如果后续实际开展新闻、出版、教育培训等受专门监管的服务，另行核对前置资质。

## 现在就能准备的材料

- 营业执照、统一社会信用代码、主体/网站/APP 负责人信息、必要授权书、联系地址与电话。
- 根域名实名资料、云服务器订单和公网 IP、网站/APP 名称与业务描述。
- Android/HarmonyOS/iOS 的正式包名、签名证书、公钥/指纹等资料。当前工程仍有 `com.example.qflistudio`，正式发行前应确认固定标识和签名，再提交备案。
- 用户协议、隐私政策、社区规则、投诉举报与申诉说明、账号注销说明。卖会员时另加会员权益与退款规则，明确永久权益和云服务期限。
- 内容审核负责人和日常流程、安全评估材料、应急联系人、日志与数据保护措施。

备案通过后，在官网和 APP 的显著位置展示真实备案编号，并按要求链接备案查询系统。没有获批编号时不要填写示例号码冒充备案。

## 讨论区开放前的开发工作

| 优先级 | 功能 | 验收要点 |
| --- | --- | --- |
| P0 | 真实身份认证与发布权限 | 后台实名、前台昵称；手机等认证方式按规定实现。用户名密码登录、OAuth 登录成功都不能直接当作已完成实名。服务端对发帖/评论等接口校验身份状态 |
| P0 | 举报与申诉 | 帖子、评论和账号可举报；有受理编号、处理状态和申诉入口，管理员能追踪闭环 |
| P0 | 审核后台 | 待审/公开/驳回/隐藏/删除/封禁等状态；审核和恢复有操作记录；有审核员与负责人 |
| P0 | 处置与巡查 | 对违法不良信息及时停止传播、处置并留存记录，按规定报告；制定巡查和应急流程 |
| P0 | 协议、隐私与注销 | 首次使用的必要告知和授权，隐私入口长期可见；能注销账号并说明内容与备份的处理方式 |
| P0 | 身份与权限安全 | 限流、反刷、管理端鉴权、操作审计；身份信息最小化收集、加密存储、限制访问 |
| P0 | 日志与备份 | 建立适用的网络安全日志留存制度（依法至少六个月等要求），区分网络日志、审核记录和用户内容的保存依据；备份可恢复、删除有流程 |
| P0 | 云端终端隔离 | 现有在线终端不能只靠“每用户一个目录”隔离；应使用受控沙箱/容器、CPU/内存/时长/网络限制和配额 |
| P1 | 社区信用与新用户策略 | 新用户限频、风险内容审核、信用管理和申诉；避免用积分或会员身份绕过审核 |

普通技术讨论可以采用适合规模的人工审核加风险拦截。对新闻信息提供跟帖评论服务时，规定明确要求先审后发。不要把“接入敏感词过滤”当作完成全部审核义务。

当前仓库已有账号、帖子、评论、签到和部分审计界面；**尚未因此具备完整的实名验证、举报申诉、内容审核及运营制度**。这些需要客户端、后端和实际运营人员共同完成。当前工作区没有后端源码，本次没有实施服务端实名/支付/审核系统。

## 推荐上线顺序

1. 固定运营主体、根域名归属、正式包名和签名，向接入商核对社区业务及收费方式。
2. 准备网站/APP 备案资料，同时完成协议、举报、实名和审核后台。
3. 完成适用的安全评估和报告提交、配置 HTTPS，测试账号注销与应急下线流程。
4. 先邀请小范围用户测试技术社区，控制发帖频率和在线终端资源。
5. 正式开放后完成适用的公安联网备案流程、展示备案号，安排持续审核和投诉处理。
6. 支付、验权和会员协议验证完成后，再开始收取会员费。

工信部 APP 备案通知规定，材料齐全准确时省级通信管理局应在二十个工作日内备案；接入商前置审核、补材料等时间另计，不应据此承诺确定上线日期。

## 已核对的官方依据

1. [工业和信息化部关于开展移动互联网应用程序备案工作的通知（工信部信管〔2023〕105号）](https://www.gov.cn/zhengce/zhengceku/202308/content_6897341.htm)：APP 主办者备案、主体与域名资料、分发和备案号展示要求。
2. [互联网论坛社区服务管理规定](https://www.cac.gov.cn/2017-08/25/c_1121541921.htm)：论坛定义、实名、审核巡查、个人信息保护、举报处理责任。
3. [互联网跟帖评论服务管理规定（2022年修订）](https://www.cac.gov.cn/2022-11/16/c_1670253725725039.htm)：评论/回复/点赞等服务、真实身份认证、审核、申诉和安全评估。
4. [具有舆论属性或社会动员能力的互联网信息服务安全评估规定](https://www.cac.gov.cn/2018-11/15/c_1123716072.htm)：论坛等形态的适用范围、开展评估和上线前提交报告。
5. [工信部备案查询系统](https://beian.miit.gov.cn/) 与 [公安备案平台](https://beian.mps.gov.cn/)：办理/查询入口。

本清单用于产品实施安排；具体经营许可分类、个体工商户主体适用性、评估渠道和属地流程应在上线前向主管部门及接入商确认最新要求。
