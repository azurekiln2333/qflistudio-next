## 文件分享

Android、iOS、鸿蒙分别执行。
使用新建的测试项目和测试文件。

1. 在微信中打开测试 PDF。
2. 选择“用其他应用打开”。
3. 检查列表是否包含 QFLI。
4. 选择 QFLI。
5. 将文件放进测试项目。
6. 检查文件名和文件内容。
7. 再次分享另一份文件。
8. 将文件附到已有 agent 会话。
9. 检查附件显示和读取结果。

预期：两种目标都能接收文件。
预期：原文件保留。
记录系统版本、来源应用和失败提示。

## 外部文件夹

iOS 和 macOS 分别执行。
选择专门用于验收的外部目录。

1. 在系统选择器中授权外部目录。
2. 打开目录中的测试文本。
3. 修改文本并保存。
4. 在 Files 或 Finder 中检查内容。
5. 关闭 QFLI。
6. 重新打开 QFLI。
7. 再次读取并保存测试文本。

预期：重启后无需重新选择目录。
预期：写入结果出现在原目录。
另用 iCloud 占位文件检查下载后的读取。
授权失效时应保留项目文件。
不能把访问失败视为空目录。

## Agents 首页

1. 连接一台已配对的电脑。
2. 在电脑启动一个测试会话。
3. 打开手机首页的 Agents 标签。
4. 检查设备名、状态和工作目录。
5. 点开该会话。
6. 检查编辑器首帧的位置。
7. 检查当前选中的会话。

预期：首帧显示 Agent 面板。
预期：选中的会话与首页条目一致。
离线快照应等待主机首份列表再更新。
主机返回空列表后应删除旧条目。

## 电脑项目同步

使用不含个人文件的临时项目。

1. 在电脑项目中新建 A 和 B。
2. 在手机查看该项目的会话。
3. 检查确认前是否下载项目文件。
4. 确认后执行首次同步。
5. 在电脑上修改 A。
6. 在电脑上删除 B。
7. 在手机手动执行同步。
8. 检查 A 的内容和 B 的删除结果。

预期：确认前不下载项目文件。
预期：再次同步只传变化的文件。
预期：同步结果与电脑当前文件一致。

## LCSign 覆盖安装

这项检查用于定位安装丢文件。
外部目录功能不能代替此项检查。

1. 将现有项目备份到应用目录外。
2. 在应用目录新建测试文件 A。
3. 在独立外部目录新建测试文件 B。
4. 记录安装前版本和构建号。
5. 记录重签后的包名和签名身份。
6. 用同一证书覆盖安装新版本。
7. 首次启动前检查 A 和 B。
8. 首次启动后再次检查 A 和 B。
9. 保存安装日志和启动日志。

Files 单次列表可能尚未刷新。
应结合安装日志或文件共享工具确认。
安装后即丢失时，检查容器复用。
首次启动后才丢失时，检查备份恢复记录。
文件仍在但项目不可见时，检查路径注册。
