# 首页 Agents 标签

## 背景

父任务 `11-23-mobile-files-agents` 的第 9 到第 11 条需求落在本任务。
手机上要能一眼看到各端的会话。
点一条会话要直达编辑器的 Agent 面板。

现状：

- 会话列表只出现在编辑器的 Agent 面板里。首页看不到会话。
- 编辑器页自己建 hub。首页没有 hub。
- 会话模型有工作目录。模型没有设备名和系统信息。

## 需求

### R9 首页 Agents 标签

R9.1 首页项目列表旁增加一个 Agents 标签。
R9.1a Agents 与其他标签共用分页控制器。
R9.1b 点击标签或左右滑动都能换页。
R9.1c 重复点击当前标签不关闭列表。
R9.1d Agents 参与标签排序并保存顺序。
R9.2 该标签只做索引。标签内不放输入框。标签内不放对话视图。
R9.3 标签列出每台主机的会话。列表经 `HarnessHub.watchSessions` 得到。
R9.4 点一条会话打开该会话项目对应的编辑器。
R9.5 编辑器首帧停在 Agent 面板。窄屏首帧落在 Agent 分段。
R9.6 该会话在首帧即为选中状态。用户不需要再点一次。
R9.7 会话在本机没有对应项目时，打开最近更新的本地项目。行为与 `openAgentsSurface` 一致。
R9.8 本机一个项目都没有时给出说明，不推空页面。

### R10 状态圆点与端标注

R10.1 每行显示一个状态圆点。圆点颜色由 `HarnessSessionStatus` 决定。
R10.2 六种状态各有各的颜色。同屏可区分。
R10.3 列表按状态排序。顺序为 `blocked`、`working`、`idle`、`done`、`exited`、`unknown`。
R10.4 同一状态内按更新时间倒序。没有更新时间时按标题升序。
R10.5 每行标注会话来自哪一端。本机、Herdr、已绑定电脑。
R10.6 已绑定电脑标注设备名。设备名未知时用主机标签。

### R11 会话详情

R11.1 每行提供一个详情入口。
R11.2 详情页显示设备名。
R11.3 详情页显示系统名。
R11.4 详情页显示系统版本。
R11.5 详情页显示主机类型。
R11.6 详情页显示会话在该设备上的路径。
R11.7 设备信息在 harness 契约里定义 Dart 字段。
R11.8 已绑定电脑的设备信息由 `11-23-device-sync` 填充。本任务只定义契约并读取。

### R12 快照优先

R12.1 打开标签先显示上次的缓存快照。
R12.2 快照显示后再订阅主机并刷新列表。
R12.3 首次使用没有快照时显示加载态。

## 约束

- Agents 功能留在原 `EditorPage`。首页到项目到编辑器的路径不变。
- 只在用户打开标签时订阅主机。应用启动不订阅。
- 保留现有行为断言。新增 Agents 后同步标签数量与顺序。
- 测试只在云端 CI 跑。本机不跑测试。
- 契约改动只允许追加类型与可选接口。不改已有字段。
- 文案走 `StudioLocalizations`。三语同时补齐。
- 不新增原生依赖。设备信息读取走已有平台通道。

## 不做

- 不做会话搜索与筛选。
- 不做首页新建会话。
- 不做内置 Agent 会话的首页索引。内置会话按项目落盘，留待后续任务。
- 不做会话流拉取。第 12 条需求由 `11-23-device-sync` 负责。

## 依赖

- 父任务约束见 `../11-23-mobile-files-agents/prd.md`。
- `HarnessHub`、`HarnessHost` 契约在 core 仓库。
- 设备信息上报在 `11-23-device-sync`。

- [ ] 打开标签时先出现上次快照。快照出现后列表自动刷新。

- [ ] 设备信息未知时详情页显示「未知」。详情页不报错。
