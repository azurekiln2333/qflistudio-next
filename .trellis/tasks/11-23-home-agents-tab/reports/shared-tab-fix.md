# Agents 标签换页修正

## 问题

5.0.11 的 Agents 是独立开关。
它通过 `_agentsOpen` 控制叠层。
它没有加入项目分页器。
用户点击其他标签时，叠层仍可能显示。

## 修正边界

首页通过 `ProjectScope.agents` 识别该页。
所有标签共用 `TabController` 和 `TabBarView`。
修改范围包含首页、顺序存储、测试和发布配置。
本次不改登录策略或文件存储逻辑。

旧顺序会在末尾追加 Agents。
点击或滑动都能选择 Agents。
重复点击保留当前页面。
拖动排序后保留 Agents 的页面状态。
首次选择前不创建会话内容。
