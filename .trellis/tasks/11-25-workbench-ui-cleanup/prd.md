# 大屏工作台界面整改

## 背景

v5.0.13 的平板与 PC 工作台可用性差。
用户在 2026-11-25 列出以下问题：

1. 点 Agents 会话弹出"Agents 面板在编辑器里，先打开一个项目"。
   来源：`lib/harness/ui/agents_entry.dart:91`。
2. 同一动作有多个入口。
   左侧图标栏、编辑器顶栏、快捷栏、侧栏"文件|会话"开关和右侧 Agent 窄条重复。
3. PC 与平板显示整条符号栏 `SymbolsBar`。
   符号栏只服务手机软键盘。
4. 打开项目后，点项目列表没有反应。
5. 项目列表和文件树分属两个图标。
   用户要求合并成一层，左右切换。
6. 缺少桌面快捷键。例如 Ctrl+加号 / Ctrl+减号 不能缩放界面。

## 形态判定（保持不变）

- Windows、macOS、Linux 判为桌面。
- 安卓、iOS、鸿蒙先问原生通道 `qflistudio/form_factor`。
- 原生失败时，屏幕逻辑短边 ≥ 600 判为平板，否则判为手机。
- 手机使用 `HomePage`。平板和桌面共用 `LargeScreenWorkbench`。

本任务不改判定逻辑，也不改手机界面。

## 需求

R1 手机界面与手机交互保持不变。
R2 大屏点 Agents 会话直接打开会话，不弹"先打开项目"。
R3 桌面本机会话的目录存在时，自动登记该目录并打开。
R4 会话找不到可用项目时，在中央区域只显示对话。
R5 大屏的每个动作只保留一个可见入口。
R6 大屏默认隐藏符号栏。
R7 设置页提供"大屏显示符号栏"开关，默认关闭。
R8 大屏隐藏编辑器快捷栏 `EditorQuickBar`。
R9 快捷栏里的动作改由顶栏"更多"菜单、状态栏或快捷键承载。
R10 左侧图标栏把"项目"和"文件"合成一个"资源管理器"。
R11 资源管理器在同一块侧栏里左右切换项目列表与文件树。
R12 点项目列表里的项目：打开该项目，侧栏滑到它的文件树。
R13 点已打开的项目：切到该项目，侧栏滑到它的文件树。
R14 文件树顶部提供返回项目列表的按钮。
R15 Ctrl+加号、Ctrl+等号放大界面。Ctrl+减号缩小界面。Ctrl+0 复原。
R16 界面缩放范围 50%–200%，步长 10%，重启后保留。
R17 macOS 用 Cmd 代替 Ctrl。
R18 大屏提供"快捷键表"一节列出的快捷键。
R19 按钮提示文字带上对应快捷键。
R20 不新增页面层级，不新增编辑器实例。
R21 大屏视觉遵循 MD3。桌面在 MD3 基础上按 IDE 习惯提高密度。
R22 消除 design.md 10.1 列出的 V1–V11 手机化问题。
R23 侧栏与 Agent 栏可拖动调整宽度。
R24 大屏菜单显示快捷键。

## 快捷键表

| 快捷键 | 动作 | 作用范围 |
| --- | --- | --- |
| Ctrl+= / Ctrl++ / Ctrl+NumpadAdd | 放大界面 | 全局 |
| Ctrl+- / Ctrl+NumpadSubtract | 缩小界面 | 全局 |
| Ctrl+0 / Ctrl+Numpad0 | 复原界面缩放 | 全局 |
| Ctrl+B | 显示或收起侧栏 | 工作台 |
| Ctrl+Shift+E | 资源管理器 | 工作台 |
| Ctrl+Shift+A | Agents 列表 | 工作台 |
| Ctrl+, | 设置 | 工作台 |
| Ctrl+` | 显示或收起终端 | 编辑器 |
| Ctrl+J | 显示或收起底部面板 | 编辑器 |
| Ctrl+L | 显示或收起 Agent 栏 | 编辑器 |
| Ctrl+W | 关闭当前文件标签 | 编辑器 |
| Ctrl+Tab / Ctrl+Shift+Tab | 下一个 / 上一个文件标签 | 编辑器 |
| Ctrl+N | 新建文件 | 编辑器 |
| F5 | 运行 | 编辑器 |
| Ctrl+S / Ctrl+F / Ctrl+G / Ctrl+I | 保存 / 查找 / 跳行 / 格式化 | 编辑器（已有） |

焦点在终端时，Ctrl+W、Ctrl+J、Ctrl+L 交给终端。

## 验收

- A1 大屏点任意 Agents 会话，都不出现"先打开一个项目"弹窗。
- A2 桌面打开一个目录未登记的本机会话：目录登记为项目，编辑器打开，右侧显示该会话。
- A3 会话目录不存在：中央显示对话，侧栏仍可操作。
- A4 大屏编辑器不显示符号栏和快捷栏。手机仍显示两者。
- A5 打开设置开关后，大屏显示符号栏。
- A6 大屏顶栏不出现"打开文件树""暂时收起编辑器""文件|会话"按钮。
- A7 大屏右侧 Agent 栏收起后不留窄条。
- A8 图标栏只剩：资源管理器、Agents、工具、教程、设置、头像。
- A9 打开项目 A 后再点项目 B：编辑器切到 B，侧栏显示 B 的文件树。
- A10 文件树点返回：侧栏回到项目列表，编辑器不变。
- A11 Ctrl+加号三次后界面为 130%，重启后仍为 130%，Ctrl+0 回到 100%。
- A12 "快捷键表"里每个快捷键在 Windows 上可用。
- A13 原有测试不改断言即可通过。为手机写的测试注入 `AppFormFactor.phone`。
- A14 云端 CI 全绿。本机不跑测试、不开模拟器。
- A15 design.md 10.4 的视觉验收全部通过。
