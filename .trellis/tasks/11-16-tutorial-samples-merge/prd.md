# 教程页与示例代码页合并（Pi B）

父任务：`.trellis/tasks/11-16-home-tutorial-tools-ui`。先读父任务的 `pi-rules.md`。

## 目标

教程和示例代码现在是两页。两页各有一条语言 chip 栏，chip 换行后占满屏幕。合并成一页，栏目单行显示。

## 需求（第一部分：合并）

- R6 教程和示例代码放在同一页。
- R6 顶栏标题是「教程」。
- R6 教程和示例代码共用一条语言栏。
- R6 语言栏是横向单行。chip 多时横向滚动，不换行。
- R6 页面里的每一条栏（语言栏、教程与示例代码的切换栏）都是单行。
- R6 在语言栏选中一种语言后，教程和示例代码都按这种语言显示。
- R6 教程原有的功能不变（搜索、打开、进度等现有行为）。
- R6 示例代码原有的功能不变（浏览、打开、复制、运行等现有行为）。
- R6 应用内不再有独立的「示例代码」页入口。原入口改为打开合并页的示例代码部分，或者删除。

## 需求（第二部分：netrix 第 3 批工具）

- 合并提交之后，移植 `research/netrix-tools-inventory.md` 里分给第 3 批的工具。
- 移植规则见父任务 `design.md` 3.2 和 `research/tools-port-contract.md`。
- 移植要求与 Pi D 的 `prd.md`「移植要求」一节相同。
- 清单里第 3 批为空时，跳过这一部分，并在报告里写明。

## 约束

- 不改主页文件。不改工具页框架文件（那是 Pi C 的）。
- 教程页现有的搜索框保持不变。集成阶段再统一组件。
- 教程内容和示例代码内容（数据文件）不改。
- 新增文字跟随现有多语言方式。

- [ ] 选语言后教程列表和示例代码列表都被过滤。有组件测试。
- [ ] 应用内找不到独立的示例代码页入口。报告写明每个原入口的处理。
