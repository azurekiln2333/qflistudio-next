# PRD：桌面端与手机端远程互联

## 目标

让 QFLIStudio 手机端安全连接桌面电脑，并读取桌面 Agent 会话。

## 背景

- 任务 11-20 已迁入远程终端、Herdr、Claude 和 Codex 会话。
- 预览版已有手机端配对和会话界面。
- CloudTerminal companion 已支持 Windows、macOS 和 Linux。
- Windows 助手显示二维码和配对码。
- macOS、Linux 启动脚本只显示配对码，未显示配对链接。
- QFLI 登录、relay 账号和设备绑定尚未接通。
- 现有设备配对与 Agent 会话协议继续作为兼容基线。

## 需求

R1. Studio 桌面版在 Windows、macOS、Linux 显示一次性配对码。
R2. Studio 桌面版显示二维码和可复制的配对链接。
R3. 手机端保留手动配对和原有远程会话。
R4. 手机端使用 QFLI 账号查看绑定电脑和在线状态。
R5. 手机端可绑定电脑，也可撤销绑定。
R6. 桌面版和手机端都能读取真实 Agent 会话。
R7. 账号令牌、relay 令牌和配对密钥分开保存。
R8. QFLI 服务使用单次授权票据向 relay 换取令牌。
R9. relay 撤销绑定后拒绝旧令牌，并断开现有连接。
R10. 绑定电脑继续支持终端、Herdr、Claude 和 Codex。
R11. 自动检查覆盖账号隔离、绑定、撤销和旧流程兼容。

## 验收标准

AC1. Studio 桌面版三种系统都能显示有效配对码。
AC2. 三种系统都能复制手机端可解析的链接。
AC3. 桌面版可读取真实 Herdr、Claude 和 Codex 会话。
AC4. 已登录用户能查看自己的电脑和在线状态。
AC5. 用户能绑定电脑，并通过手机连接到电脑会话。
AC6. 用户撤销后，旧令牌无法连接或刷新。
AC7. 其他账号看不到未授权设备。
AC8. 手动配对继续可用，四种远程会话保持兼容。
AC9. 日志、测试输出和客户端配置不泄露令牌或设备密钥。
AC10. 服务、relay、客户端和桌面端检查覆盖目标路径。

## 约束

- 账号身份使用 QFLI 当前登录，不引入第二套用户账号。
- relay 账号标识使用经验证的网关 sub。
- QFLI JWT 不得发送给 relay。
- 设备绑定必须同时验证账号授权和一次性配对码。
- 撤销绑定必须回收设备令牌并断开已连接客户端。
- 不改变终端、Herdr、Claude、Codex 的会话协议。
- 不部署服务，不发布新版本，不修改 CloudTerminal 源仓。
- macOS、Linux 的桌面版必须提供图形配对和会话入口。
- CLI 启动方式作为无桌面环境下的备用路径。
- 保留现有工作树里的用户改动，不重置、不清理、不覆盖。

## 范围外

- 公网 relay 部署和生产数据库迁移。
- 自动发现局域网设备。
- 自动读取或导入 CloudTerminal 本机密钥。
- 自动批准远程命令、Claude 权限或 Codex 操作。
- 发布签名、商店分发和真实设备验收。
