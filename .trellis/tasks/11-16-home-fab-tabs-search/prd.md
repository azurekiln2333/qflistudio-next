# 主页：悬浮按钮、标签排序、折叠搜索（Pi A）

父任务：`.trellis/tasks/11-16-home-tutorial-tools-ui`。先读父任务的 `pi-rules.md`。

## 目标

修正主页的四个问题：云端项目只能从右上角菜单新建，标签不能排序，默认顺序不合适，搜索样式与教程页不一致。

## 需求

- R1 当前标签是「云端项目」时，点悬浮按钮进入新建云端项目的流程。这个流程就是原先右上角菜单「新建云端项目」触发的流程。
- R1 其他标签下，悬浮按钮的行为与改动前一致。
- R2 删除右上角菜单的「新建云端项目」项。菜单的其他项不变。
- R3 用户长按一个主页标签后可以拖动它来排序。
- R3 应用把排序结果保存在本机。重启后顺序保留。
- R4 默认顺序：历史项目、工作区、全部项目、收藏项目、云端项目。
- R4 没有保存记录的用户看到默认顺序。
- R5 主页搜索改成一个搜索图标。点图标后展开搜索框。
- R5 搜索框的外观与教程页的搜索框一致。
- R5 搜索的过滤逻辑与改动前一致。
- R11 项目列表里，项目名称旁边的语言标签现在是蓝色圆圈。把它改成椭圆形（左右两端为半圆的胶囊形）。
- R11 语言标签的字体改小。文字在标签内完整显示，不被裁切。
- R11 语言标签的颜色保持现在的蓝色。标签宽度随文字变化。
- R11 同一个语言标签组件出现在多个列表时，所有列表都使用新样式。

## 约束

- 只改主页相关文件。不改教程页、示例代码页、工具页的文件。
- 折叠搜索做成可复用组件，放在新文件里。
- 某个配置下没有「云端项目」标签时（例如离线配置），行为保持改动前的样子。
- 标签的点击切换、滑动切换、角标等现有行为不变。
- 长按拖动不得与标签上已有的长按行为冲突。有冲突时在报告里写明取舍。
- 新增文字跟随现有多语言方式。

## 验收标准

- [ ] 在「云端项目」标签点悬浮按钮，进入新建云端项目流程。有组件测试。
- [ ] 在另外四个标签点悬浮按钮，行为与改动前一致。有组件测试。
- [ ] 右上角菜单没有「新建云端项目」。有组件测试。
- [ ] 无保存记录时，标签顺序是：历史项目、工作区、全部项目、收藏项目、云端项目。有测试。
- [ ] 长按拖动后顺序改变并被保存。重建页面后顺序保留。有测试。
- [ ] 保存的顺序里有未知标识或缺少标签时，应用不崩溃，缺少的标签按默认顺序补在后面。有测试。
