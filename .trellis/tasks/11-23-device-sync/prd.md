# 电脑改动回到手机

父任务：`11-23-mobile-files-agents`。
本任务对应父需求的第 7、8、12 项，以及第 11 项的电脑侧上报。

## 目标

手机拿到电脑上的项目改动。
git 项目按 origin 拉取。
非 git 项目按需同步。
没有本地项目的会话先看会话流。

## 背景

1. 已绑定电脑的通道只传会话和终端，不传文件。
2. `lib/remote_control` 有完整的中继与配对实现。
3. `companion/remote_agent` 是电脑侧的 Node agent。
4. `qfli_git` 提供本地 git 操作，Dart 侧走 FFI。
5. 会话落盘在 `agent_sessions/`，单文件上限 8 MB。
6. 中继单帧上限 4 MiB，文件必须分块。

## 需求

### DR1 git 项目按 origin 拉取

电脑上的项目是 git 仓库时，手机不传文件。
手机用 `qfli_git` 从同一 origin 克隆。
首次克隆用完整克隆。
之后的更新只抓增量。

### DR2 浅克隆的核实结论

`qfli_git` 打包 libgit2 1.9.7。
C 接口 `qg_clone` 与 `qg_fetch` 都没有 depth 参数。
Dart 接口 `QfliGit.clone` 与 `fetch` 也没有 depth 参数。
结论：当前不能浅克隆。
本任务不修改 `qfli_git`。
本任务退化为完整克隆，并把 depth 记为后续跟进项。

### DR3 非 git 项目按需同步

只在用户点「同步」时传输。
先取清单，清单含路径、大小、哈希。
只传变化的文件。
电脑上删掉的文件，手机上也删掉。
先写暂存目录，检查哈希后再原子改名。

### DR4 默认忽略表

忽略表带版本号，两端一致。
默认忽略四类内容。
构建产物、依赖目录、日志、harness 会话记录。

### DR5 缓存上限与淘汰

同步得到的副本放在应用数据目录。
总占用有上限，默认 512 MiB。
超限时淘汰最久未用的项目。
正在打开的项目不参与淘汰。

### DR6 局域网直连优先

先试局域网直连。
直连失败后退回中继。
中继只转发，不存文件。

### DR7 电脑上报设备信息

电脑上报设备名、系统、系统版本。
字段名与 `11-23-home-agents-tab` 对齐。
原有字段保留，新增字段可选。

### DR8 占位项目

会话在本机没有对应项目时，建占位项目。
占位项目放在应用数据目录。
占位项目记录电脑标识、会话号、电脑上的路径。

### DR9 会话流缓存

会话流写进占位项目下的缓存文件。
单个会话的缓存有上限。
超限时丢最旧的记录。

### DR10 项目文件按确认下载

占位项目默认不含项目文件。
用户确认后才拉取项目文件。

### DR11 占位项目随会话清理

会话结束时判断是否拉过文件。
从未拉过文件就删掉占位项目。
拉过文件就把占位项目转成普通项目。

## 约束

1. Agents 功能留在原 `EditorPage`。
2. 首页到项目到编辑器的路径不变。
3. 同步少占服务器。中继不存文件。
4. 手机不无限写入。只在用户触发时拉取。
5. 原有测试不改也要通过。
6. 测试只在云端 CI 跑，不在本机跑。
7. 不修改 `qfli_git`，它有独立负责人。
8. 不修改 `lib/harness/harness_host.dart` 契约。

## 验收标准

- [ ] git 项目同步后，手机拿到与电脑同一提交的文件。
- [ ] 非 git 项目同步后，只传变化的文件。
- [ ] 电脑删掉的文件，手机同步后也消失。
- [ ] 同步中途失败后，旧清单与旧文件仍可用。
- [ ] 缓存超过上限时，淘汰最久未用的项目。
- [ ] 直连失败后，同步经中继仍能完成。
- [ ] 电脑上报设备名、系统、系统版本。
- [ ] 无本地项目的会话能看到会话流。
- [ ] 项目文件要用户确认后才下载。
- [ ] 会话结束且无文件时，删掉占位项目。
- [ ] 会话结束且已拉文件时，占位项目转成普通项目。
- [ ] 原有测试不改也通过。
