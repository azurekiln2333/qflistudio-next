# Brief C：各平台系统权限与工具可用性

先读同目录 `RULES.md`。

输出文件：`.trellis/tasks/11-12-agents-workbench/research/C-platform-permissions.md`

## 调查内容

1. 列出项目实际支持的平台（看仓库中的平台目录和构建配置）。
2. 找出工作区文件当前的存放位置：应用沙箱、外部存储、用户选择的目录。给出代码位置。
3. 列出各平台当前声明的权限：`AndroidManifest.xml`、ohos `module.json5`、iOS `Info.plist`、macOS entitlements。
4. 对每个平台回答下列问题，并注明来源（官方文档 URL 或代码位置）：
   - agent 能否读写工作区文件
   - agent 能否访问沙箱外的用户目录，需要哪种授权，授权能否持久化
   - 应用能否执行进程或 shell
   - 应用切到后台后，agent 回合能否继续，限制是什么
   - 应用商店审核对「执行下载的代码」「AI 生成内容」的要求
5. 给出工具可用矩阵：行是工具（读、写、编辑、搜索、列目录、终端、联网抓取），列是平台。
6. 对每个不可用的格子给出降级方案。
7. 结论节必须回答：用户担心的移动端系统权限问题是否阻塞 prd.md 的 R7。

允许联网查官方文档。
