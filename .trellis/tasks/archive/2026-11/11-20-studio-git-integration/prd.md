# Studio Git 插件与界面接入

## 目标

用户能从项目打开 Git 页面。
用户能在移动端操作本地仓库。
交付包含 Git 界面的云端安装包。

## 当前缺口

- `GitService` 只支持桌面命令行。
- `GitPage` 拒绝移动端本地项目。
- 主项目未依赖 `qfli_git`。
- 插件缺少单文件暂存和取消暂存。
- 插件缺少差异、历史和远端管理接口。
- 编辑器入口固定使用主项目。

证据见 `research/studio-integration.md`。
源码基线见 `research/baselines.md`。

## 范围

| 编号 | 要求 | 验收 |
| --- | --- | --- |
| R1 | 接入 Android、iOS、OHOS 原生插件 | A1 |
| R2 | 显示分支、状态、差异和历史 | A2 |
| R3 | 支持暂存、取消暂存和提交 | A3 |
| R4 | 支持分支创建、切换和合并 | A4 |
| R5 | 支持远端配置、获取和推送 | A5 |
| R6 | 支持克隆并注册项目 | A6 |
| R7 | 保护编辑器缓冲区和项目归属 | A7 |
| R8 | 保留桌面 Git 和云端 Git | A8 |
| R9 | 交付可追溯的云端安装包 | A9 |

移动端明确区分获取与合并。
桌面保留现有拉取变基语义。
本地提交只包含用户暂存的文件。
页面分别提供全部暂存和提交操作。
冲突页面列出文件并支持完成合并提交。
令牌仅供本次页面会话使用。
Git 令牌与 Studio 登录令牌独立。
新增文件级操作仅用于本地仓库。
云端保留现有服务器操作。

## 验收条件

- A1：移动端项目能打开可操作的 Git 页面。
- A1：桌面启动不加载移动端原生库。
- A2：页面区分暂存区和工作区状态。
- A2：空仓库、二进制和大差异有明确状态。
- A3：本地单文件暂存和取消暂存正确。
- A3：空消息和未解决冲突阻止提交。
- A3：失败操作不得显示成功。
- A4：分支切换不得覆盖未保存内容。
- A4：合并冲突可见且保留真实仓库状态。
- A5：HTTPS 获取和推送使用独立凭据。
- A5：错误、日志和产物不得泄露令牌。
- A6：克隆成功后注册项目。
- A6：失败清理仅涉及本次创建的目录。
- A7：Git 入口捕获当前文件所属项目。
- A7：切换标签不得改变操作目标。
- A7：文件变化后刷新干净缓冲区和文件树。
- A8：桌面凭据助手和 SSH 行为保留。
- A8：云端项目继续调用服务器 Git。
- A9：GitHub 云端通过原生及应用检查。
- A9：安装包记录应用、内核和插件提交。
- A9：原生库与 Dart 绑定版本匹配。
- A9：用户能下载包含 Git 界面的预览包。

## 执行约束

- 仅在隔离工作区编写产品代码。
- 不修改原 `cloudterminal` 工作区。
- 不覆盖其他会话的未提交文件。
- 不在本机测试或构建。
- 不启动模拟器、虚拟机或设备工具。
- 本机仅做阅读、格式和静态检查。
- 通过 GitHub 发布预览包。
- 不向 CNB 推送发布标签。
- 用户已要求完成计划后直接派 Pi。
