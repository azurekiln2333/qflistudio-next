# 预览版安装检查

本文用于云端预发布完成后的安装验收。
安装包版本为 5.0.5。
发布标签为 `v5.0.5-remote.2`。
下载链接和 SHA-256 以最终发布报告为准。

## Android

1. 下载 `qflistudio-5.0.5-android-arm64-v8a.zip`。
2. 解压文件。
3. 安装包内的 APK。
4. 打开应用的工具页。
5. 进入“远程电脑”。

该 APK 使用调试证书。
它无法覆盖签名不同的已安装版本。
更换已安装版本前，请先备份项目。

## Windows 助手

1. 下载 `qfli-remote-assistant-5.0.5-windows-x64.zip`。
2. 将整个压缩包解压到可写目录。
3. 打开 `Start-QFLI-Remote.cmd`。
4. 保持手机和电脑连接同一局域网。
5. 在助手侧栏打开“配对”。
6. 记下页面显示的中继地址和短码。
7. 在手机的“远程电脑”页选择“输入短码”。
8. 填写服务器地址和配对码。
9. 点击连接。

手机端尚无相机扫码功能。
请使用上述手动配对方式。

助手已包含 Node.js 和代理依赖。
Herdr、Claude 和 Codex 使用电脑上的安装。
这些工具使用用户自己的登录状态。
助手沿用用户的 `~/.cloudterminal` 配置。
修改中继模式后，请关闭并重新打开助手。

## 验收项目

- 确认远程会话列表可见。
- 确认终端可以输入并收到输出。
- 确认 Claude 消息进入 Claude 会话。
- 确认切换会话后仍能收到新输出。
- 确认返回 Studio 后能再次打开远程电脑。
- 确认暂时断网后可以重新连接。

云端检查使用真实中继和脚本化模型响应。
配对检查使用本机回环网络。
云端检查没有验证实体手机或真实账号。
多网卡和防火墙行为仍待用户安装验收。

## 范围

本版包含远程电脑模块和思考流界面。
本版尚未接入 Studio 的 Git 插件界面。
iOS 和 OHOS 包需要签名后才能安装。
Windows 包未签名。
macOS 包采用临时签名，尚未公证。
