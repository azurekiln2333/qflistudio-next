# 平板与 PC 大屏工作台

## 目标

手机保留独立界面和两层导航。
平板和 PC 共用重新设计的大屏工作台。
大屏启动后直接显示工作台。
项目列表与编辑内容位于同一个界面。
GitHub 仓库加入手机首页标签。
个人页面统一管理 GitHub 连接。

- Core 入口 `lib/app.dart:151` 统一进入 `HomePage`。
- 首页 `lib/pages/home_page.dart:158` 按窗口宽度切换导航。
- 编辑器仍混合窄屏与宽屏布局。
- 项目、账号、文件和会话服务已经位于 Core。
- 旧工作台曾因重复编辑器与多层路由返工。
- 旧审计见 `../11-12-agents-workbench/research/F-rework-audit.md`。

  证据为 `lib/editor/retained_editor_host.dart:523`。

  证据为 `lib/editor/editor_page.dart:4363`。
- 已有目录通过 `lib/store/project_store.dart:584` 登记。

  证据为 `lib/pages/home_page.dart:1505`。

  证据为 `lib/pages/git/github_repository_picker.dart:119`。

## 约束

- 与 Agents 5.0.12 修复使用不同工作树。
- 手机现有行为断言继续保留。
- 测试只在云端 CI 运行。
- 本机只运行格式检查和静态分析。
- 不复制项目存储、账号状态或 Agent 运行时。
- 不修改现有登录策略、项目格式或业务协议。
- 不替换已发布的 5.0.11 安装包。
- 断开 GitHub 不删除已克隆的本地项目。
- 窗口缩小只折叠侧栏，不切换成手机导航。
- 已有 GitHub 安全凭据继续由原控制器管理。
- 本次不增加其他 Git 托管平台。
