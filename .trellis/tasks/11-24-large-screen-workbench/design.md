# 大屏工作台与 GitHub 入口设计

## 界面结构

手机保留“项目列表页 → 编辑页”。
首页连接成功后增加 GitHub 标签。
该标签直接显示仓库列表。
个人页面负责连接和断开 GitHub。

PC 和平板启动后显示工作台。
左侧为 52 像素图标栏。
项目、文件树和 Agents 共用 300 像素侧栏。
中央显示当前项目的编辑内容。
选项目只切换中央内容。
无项目时，中央显示打开项目入口。
头像固定在图标栏底部。
头像打开个人页面。
工具、教程和设置入口继续可达。

侧栏可以折叠。
重复点击选中图标可折叠或展开侧栏。
切换图标只修改侧栏内容。
各列表保留搜索、展开和滚动状态。
GitHub 仓库位于项目侧栏的来源选择中。
Agent 对话继续使用已有会话和运行时。
侧栏只负责选择会话。
现有对话区不另建运行时。

## 最小行为差距

当前首页和编辑器属于两个显示层。
首页侧栏会受到编辑器叠层遮挡。
直接包装首页不能满足常驻图标栏。
宿主必须给大屏提供统一的布局边界。
手机宿主继续使用原路径。

## 组成与状态归属

`lib/app.dart` 选择手机入口或大屏入口。
同一个 `RetainedEditorController` 持有编辑会话。
大屏壳位于导航器和保活编辑器的共同宿主。
壳提供图标栏、侧栏槽和中央内容槽。
启动、恢复完成页先于工作台显示。

`RetainedEditorHost` 保留已有会话身份。
大屏只修改会话的显示位置。
根弹窗必须覆盖图标栏和编辑内容。
个人页面与工具页面不能出现在编辑器背后。
离开工作区只隐藏编辑器。
返回后恢复原活动会话。

`EditorPage` 继续持有编辑控制器。
它向宿主提供当前项目的文件侧栏内容。
该接口同时提供文件回调和活动状态。
文件树通过稳定槽位保留元素身份。
切换侧栏不重建编辑控制器。
未访问的侧栏按需创建。
隐藏的侧栏停止输入、焦点和辅助功能响应。
同一时刻只有一个可见主侧栏。

新增大屏专属壳和主题文件。
手机组件不读取大屏主题参数。
两端共用项目、账号、文件和会话服务。
小范围抽取现有组件时保留原默认行为。

## 设备类别与宽度

设备类别独立于窗口宽度。
Windows、macOS 和 Linux 使用大屏界面。
iOS 通过系统设备类别识别 iPad。
OHOS 通过系统设备类型识别平板。
Android 通过完整显示区域的逻辑短边判断。
Android 的阈值为 600 逻辑像素。
Android 缺少统一的平板硬件标识。
该规则属于分类近似。
实现前检查目标 SDK 的分屏与折叠行为。

设备类别在应用入口解析。
不通过鼠标连接判断设备类别。
窗口宽度只决定侧栏常驻或抽屉布局。
大屏小窗口仍保留工作台导航。
断点集中在 `lib/layout/breakpoints.dart`。
触控按钮至少保留 44 像素有效区域。
平板分屏和软键盘须纳入云端布局检查。
折叠设备和外接显示器另列真机验收。

## GitHub 状态与列表

现有仓库选择页同时拥有认证和列表。
将界面组件拆成连接面板和仓库列表。
共享一个应用级 `GitHubAuthController`。
入口负责创建、恢复和释放该控制器。
个人页面与首页订阅同一个连接状态。
切换页面不得取消另一页面正在使用的请求。
离开连接面板时取消未完成的授权轮询。

成功连接后增加 `ProjectScope.github`。
该作用域复用首页已有分页器和顺序存储。
连接失效时保留已知账号的标签位置。
列表显示重连入口，并打开个人页面。
主动断开后隐藏 GitHub 标签。
如果当前正在该页，则回到历史页。
其他标签的相对顺序保持不变。
重新连接后恢复 GitHub 的原排序位置。

仓库列表直接提供搜索、刷新和分页。
未克隆仓库通过原克隆服务下载。
克隆进度和错误保留在当前列表中。
已克隆仓库提供打开本地项目入口。
创建仓库身份与本地项目的轻量映射。
映射仅含服务器、仓库标识和项目标识。
不把访问令牌写入项目或映射文件。
旧项目按已有 Git 远端信息补充映射。
无法匹配时保留原项目，不猜测身份。
断开连接不删除克隆文件。

## Windows 拖入目录

原生适配器接收资源管理器的目录拖入。
优先使用 runner 内的 OLE 拖放适配器。
目标窗口须包含实际 Flutter 子窗口。
注册、撤销和 OLE 生命周期必须成对。
实现时按 Windows SDK 头文件检查接口。
原生层只读取路径，不复制或移动目录。

新增独立的目录拖入通道。
协议仅传递批次标识和绝对路径列表。
应用就绪前的批次保留到订阅完成。
每个批次只消费一次。
按规范化路径复用项目。
同批次重复路径只打开一次。
重复拖入复用原编辑会话。
多个目录逐一登记，最后成功项成为当前项目。
单个目录失败不撤销其他成功项。
拖入普通文件时显示不支持提示。

登记复用 `ProjectStore.addExisting`。
该方法只登记项目，不负责打开编辑器。
打开使用已有保活控制器。
现有登记逻辑会写入项目元数据。
元数据写入失败时保留原目录和当前编辑内容。
不借用 Apple 书签接口处理 Windows 路径。
不任意拒绝可访问的网络目录。
删除项目行为不在本次改动中扩展。

## 修改边界

| 文件或目录 | 修改原因 |
| --- | --- |
| Core `lib/app.dart` | 双界面入口与共享 GitHub 状态 |
| Core `lib/shell/` | 大屏壳、图标栏、侧栏槽和个人入口 |
| Core `lib/layout/` | 设备类别与集中断点 |
| Core `lib/editor/retained_editor_host.dart` | 保留会话并嵌入中央区域 |
| Core `lib/editor/editor_page.dart` | 输出文件侧栏并复用编辑内容 |
| Core `lib/pages/home_page.dart` | 插入 GitHub 标签并保留手机导航 |
| Core `lib/pages/home_project_tabs.dart` | 动态标签与排序恢复 |
| Core `lib/pages/profile_page.dart` | GitHub 连接管理 |
| Core `lib/pages/git/` | 复用连接和仓库列表组件 |
| Core `lib/github/` | 控制器归属和本地仓库映射 |
| Core `lib/services/` | 目录拖入适配和打开协调 |
| App `windows/runner/` | 原生目录拖入与生命周期 |
| App iOS、Android、OHOS 入口 | 设备类别桥接 |
| Core 与 App `test/` | 导航、保活、GitHub 和目录拖入回归 |

## 兼容与回退

大屏改动使用独立工作树和提交。
5.0.12 的发布提交保持不变。
手机测试继续断言原导航和编辑行为。
只有新增 GitHub 入口的断言按需求修改。
回退工作台壳不删除项目或会话数据。
GitHub 映射采用独立文件和可忽略版本号。
旧版本忽略映射后仍能打开本地项目。
云端通过不等于真机拖放和触控已验收。
